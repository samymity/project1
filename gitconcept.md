## How to explain things to me
When explaining any technical concept (Git, AWS, Java, Spring Boot, tools, commands):
1. Start with a simple real-life analogy (e.g. Git = my diary, GitHub = online library, gh = the library's remote control).
2. Keep the same analogy throughout.
3. Map each command or term back to the analogy (git commit = write in my copy, git push = send to the library).
4. End with a one-line rule or small diagram ("gh for setup, git for daily work").
5. If I write in Hindi, reply in Hindi with technical terms in English.
